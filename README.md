# ◆ SwagCod

Быстрый и стабильный десктоп-клиент для кодинг-агентов. Rust-ядро + Tauri v2 +
Svelte 5. Своё агентское ядро, OpenAI-совместимый протокол провайдера.

**Весь контекст, решения и приоритеты — в [`DECISIONS.md`](DECISIONS.md).**
Это единственный источник правды по проекту; если решения там нет — оно не
принято.

---

## Стек

| Слой | Технология | Почему |
|---|---|---|
| Ядро | Rust | PTY, файлы, diff, стрим, журнал — горячий путь без GC-пауз |
| Шелл | Tauri v2 | Системный WebView вместо бандла Chromium: 4.6 МБ бинарник против 250 МБ |
| UI | Svelte 5 + Vite | Компиляция в чистый JS без VDOM — минимум оверхеда на апдейт |
| Провайдер | OpenAI-совместимый | Один клиент покрывает DeepSeek, агрегаторы, локальные llama.cpp/Ollama |

## Структура

```
crates/
  core/       домен: шина событий, сессии, state machine хода. БЕЗ tauri.
  provider/   OpenAI-совместимый клиент, SSE-парсер
  pty/        PTY, ANSI, кольцевой буфер            (этап 2)
  fsx/        файлы, watch, поиск, diff             (этап 2)
  app/        тонкая Tauri-обёртка — только окна и IPC
apps/desktop/ Svelte 5 фронтенд
tools/        скрипты замеров бюджета
bench-out/    startup.json с числами бюджета (в коммите); скриншоты игнорируются
```

`core` принципиально не зависит от `tauri`: иначе нельзя гонять headless-тесты
и бенчи, а значит нельзя мерить бюджет производительности.

## Что уже работает

**Фирменный layout SwagCod:** sidebar с Workspaces/сессиями (растягивается
мышью, сворачивается), New Session кнопка, контекстное меню сессий (правый клик),
статистика events/turns/items, waveform индикатор стрима, Chat/Trajectory tabs,
Settings dialog (General/Models/Plugins), input box с textarea и круглой
send-кнопкой, анимации sidebar-in/content-in, focus-within glow.

**Выбор модели и прав:** поповер над зоной ввода со всеми моделями провайдера —
фильтр по имени, размер контекста, скорость, способности (инструменты /
рассуждения / зрение), отметка текущей. Права задаются прямо в этом же поповере
(три режима) и уходят в ядро как `ApprovalPolicy`
(`always` / `on_dangerous` / `never`) через `set_approval_policy`; опасный режим
подсвечен красным. Температура не переопределяется: запрос уходит без поля
`temperature`, провайдер применяет своё значение по умолчанию.

**Внешний вид:** четыре темы (тёмная / светлая / контрастная / системная —
следит за `prefers-color-scheme`). Каждая тема — целостная палитра: светлая
не «белый фон с красными кнопками», а полностью сине-зелёная (акцент, ховеры,
тинты границ, свечение и даже фоновая сфера — одного семейства, переменная
`--accent-rgb`), красным во всех темах остались только ошибки и опасный режим
прав. Размер шрифта транскрипции 10–24px, масштаб всего окна 60–200%,
ширина сайдбара 200–560px, фоновые эффекты (wireframe-сфера или matrix rain) —
всё сохраняется между запусками. Любое сообщение можно развернуть на весь экран
с собственным масштабом 70–250%. Все иконки — собственные штриховые SVG
(`components/Icon.svelte`), эмодзи в интерфейсе нет.

**Студия тем:** поверх готовых палитр — свой акцент круглой палитрой
(перекрашивает кнопки, свечения и декор целиком), тонировка всего интерфейса
мягким цветовым слоем и медиафон: gif / mp4 / webm / картинка на заднем плане
(файлы хранятся в каталоге приложения, лимит 48 МБ). Всё сохраняется между
запусками.

**Статусы сессий честные:** мозг с бегущими нейронами, пока ход идёт; мигающий
красный треугольник с восклицанием, если последний ход упал; мигающая зелёная
галочка, когда ход завершился успешно. Статусы приходят из самих событий шины,
без опроса ядра. Пока нейронка думает, кнопка отправки становится стопом
(ход обрывается командой ядра), а набранные реплики встают в очередь чипами
над полем ввода и уходят сами после конца хода. Ошибка в транскрипте
подсвечивается волной цвета по всему тексту. У каждой сессии свой транскрипт:
переключение показывает её историю (догружается с ядра), а не общий чат.
Кнопка-папка в шапке сайдбара открывает список путей рабочих областей (открыть
в проводнике, копировать путь). Логотип и splash — анимированный глаз: чёрный
фон кадра вырезан luminance-маской, светится только контур зрачка.

**Оверрайды окружения:** `SWAGCOD_APPEARANCE` (dark/light/contrast/system) и
`SWAGCOD_BG_MODE` (sphere/matrix) применяются при старте поверх сохранённых
настроек — удобно для киосков, скриншотов и CI.

**Этап 0 (каркас):** шина событий с backpressure, батчинг по rAF, виртуализация
транскрипции, splash с glitch-эффектом и анимацией загрузки, wireframe-сфера +
частицы + scan lines на canvas, matrix rain как альтернативный фон (переключаемый).

**Этап 1 (живой стрим):** отправка сообщений модели через `start_turn`,
инкрементальный markdown с подсветкой синтаксиса (highlight.js), курсор при
стриме, кнопка «копировать» на код-блоках, индикатор «думает» с breathing glow,
статистика токенов и ток/с, 100k событий за 13 мс.

**Этап 2 (наполнение):** мульти-сессии, поиск по транскрипции (⌘F), палитра
команд (⌘P), экспорт в markdown, закладки на сообщения, мини-карта скролла,
drag-and-drop файлов, настройки модели/температуры с сохранением, системные
уведомления, glitch-оверлей при ошибке, Trajectory tab со списком ходов.

**Безопасность:** песочница fsx::is_within на list_dir/read_file/open_in_explorer,
.env скрыт из UI, command injection устранён, история сессии накапливается.

**Горячие клавиши:** ⌘K — ввод, ⌘P — палитра (24 команды), ⌘F — поиск,
⌘L — clear, ⌘M — выбор модели, ⌘B — свернуть/развернуть панель,
⌘= / ⌘- / ⌘0 — масштаб окна, Escape — закрыть диалоги.

## Разработка

Нужны: Rust stable (MSVC), Node 20+, pnpm 11+.

```powershell
pnpm install                                # зависимости фронтенда
cargo test --workspace                      # тесты ядра (headless)
pnpm --filter swagcod-desktop test          # тесты фронтенда
pnpm --filter swagcod-desktop check         # типы
cargo clippy --workspace --all-targets -- -D warnings

# Сборка с вшитым фронтендом (ОБЯЗАТЕЛЬНО custom-protocol!):
pnpm --filter swagcod-desktop build         # 1. собрать фронтенд в dist/
cargo build --release -p swagcod-app --features tauri/custom-protocol
# 2. результат: target/release/swagcod-app.exe

# Без --features tauri/custom-protocol бинарник будет искать localhost:5173
# и покажет ERR_CONNECTION_REFUSED. Это грабля Tauri v2 — см. DECISIONS.md §7.
```

## Замеры бюджета

Бюджет производительности — это числа, а не ощущения. Замер старта и памяти:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File tools/bench-startup.ps1 -Runs 5 -OutFile bench-out/startup.json
```

Скрипт считает память **по всей семье процессов**: Tauri поднимает WebView2
дочерними процессами, и замер по главному процессу занижает реальность в разы.

Текущие результаты — из закоммиченного `bench-out/startup.json`
(i5-10400F / 16 ГБ, Windows, прогон 03.10):

| Метрика | Цель | Факт |
|---|---|---|
| Холодный старт до окна | < 400 мс | **35 мс** медиана (худший прогон 101 мс) |
| RSS всей семьи | справочно | 326 МБ: цель по RSS отменена, D-013 |
| Private bytes нашего процесса | < 40 МБ | меряется скриптом с ревизии 7, число появится в следующем startup.json |
| Private bytes всей семьи | < 200 МБ | то же |
| Размер бинарника | — | 4.56 МБ на момент замера |
| Тесты | все зелёные | **163** (105 Rust + 58 TS) |
| Clippy | 0 warnings | ✅ |
| svelte-check | 0 errors, 0 warnings | ✅ |

Таблица переписывается только прогоном `tools/bench-startup.ps1` против
свежего release-бинарника: числа в README без строки в startup.json — ложь.
Подробнее, включая отменённую цель по RSS и причины — `DECISIONS.md` §2 и D-013.
